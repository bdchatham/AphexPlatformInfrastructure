This is a test repository for validating the Jenkins X pipeline execution workflow.

- Test configuration

## Purpose

This repository is used to test:
- Repository onboarding via RepoBinding
- Pipeline triggering on merge to main
- CDKTF synth and deploy execution
- Terraform state management
- Log accessibility
