# Golden Pipeline Catalog

This directory contains shared Tekton Tasks and Pipelines that tenants can reference.

## Contents

- Tekton Task definitions (git-clone, cdktf-synth, cdktf-deploy, upload-artifacts)
- Tekton Pipeline definitions (cdktf-deploy-pipeline)
- Runner container image Dockerfile

## Purpose

Provides versioned, reusable pipeline components maintained by the platform team.
